# FinMark Terminal Assessment

**Course:** MO-IT162 – Math for Machine Learning: Linear Algebra

**Project Title:** ML Solution EDA and DataViz

## Project Description

This project focuses on exploring and understanding FinMark's customer data through data cleaning, exploratory data analysis (EDA), and data visualization.

We worked with three datasets:
- Customer Demographics
- Customer Transactions
- Social Media Interactions

## Project Objectives

- Examine and clean the datasets.
- Identify missing values, duplicates, and unusual entries.
- Analyze customer demographics, transaction behavior, and social media engagement.
- Present findings through statistical summaries and visualizations.
- Recommend a possible machine learning application for FinMark.

## Proposed ML Solution

We recommend exploring customer segmentation to help FinMark better understand its customers and support more personalized marketing strategies.

Model training and evaluation are proposed as future work.
